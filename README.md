# Hibernate CRUD Application (PostgreSQL)

## 📌 Tech Stack
- Java
- Hibernate ORM
- PostgreSQL
- Maven

## 🚀 Features
- Insert Data
- Update Data
- Delete Data
- Fetch Records

## 🗄 Database
PostgreSQL

## ⚙ Configuration
Update database credentials inside:
src/main/resources/META-INF/persistence.xml

## ▶ How to Run
1. Clone the repository
2. Update PostgreSQL username & password
3. Run the main class
